# 보리 눈 후보 04 · 사용자 선택

흰자 41×47, 검은 눈동자 32×37, 큰 하이라이트 11×13과 작은 하이라이트.
원본 보리의 몸·입·잎·팔다리·눈 깜빡임 및 동작 키프레임을 보존하고,
`animated eyes` 레이어의 도형만 선택한 후보로 교체했다.

현재 앱의 성장 3단계 × 8동작(24개) 및 정적 대체 이미지 3종에서 사용한다.
단색 눈이 되지 않도록 하이라이트 → 눈동자 → 흰자 순서로 배열한다.
Lottie 도형은 배열 뒤에서 앞으로 그려진다.

재생성: 프로젝트에서 `node scripts/build-bori-selected-eyes.cjs`.
`selection.json`에 확정한 눈 도형을 보관한다. 원본 growth-v3 및 celebration-v1은 수정하지 않았다.

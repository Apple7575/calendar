# 보리 성장형 캐릭터 v3 — 회전·잘림 수정 및 검사 결과

## 이번 수정

- 모든 애니메이션 회전(`r`)·불투명도(`o`) 키프레임의 `s`·`e` 값을 Lottie 표준에 맞는 **길이 1의 숫자 배열**로 출력하도록 생성기를 수정했다. 정적 숫자 값은 기존 형식 그대로 유지한다.
- 큰 점프나 잎 흔들림이 들어가는 `tap`, `success`, `encourage`, `grow` 동작에서 원본에 존재하던 화면 상단 잘림도 수정했다. 몸통·잎의 디자인과 기능별 반응은 유지했다.
- GIF 미리보기 역시 올바른 배열형 키프레임과 시간 보간(베지어 이징)을 해석하도록 갱신했다. 미리보기는 **별도 SVG 렌더러**의 결과이며, 실제 Lottie iOS 런타임의 검증 결과는 아니다.

## 자동 검사

| 검사 항목 | 결과 |
| --- | --- |
| 성장 단계 | `sprout`, `growing`, `blooming` 3종 |
| 상태 | `blink`, `tap`, `success`, `failure`, `focus`, `encourage`, `sleepy`, `grow` 8종 |
| 검증한 Lottie JSON | **24개 / 24개 통과** |
| 검사한 프레임 | **2,250프레임** (각 동작의 시작부터 종료 프레임 포함) |
| 회전 애니메이션 속성 | **54개**, 모두 올바른 배열형 키프레임 |
| 불투명도 애니메이션 속성 | **15개**, 모두 올바른 배열형 키프레임 |
| 확인한 애니메이션 스칼라 키프레임 | **336개** |
| 몸통 최대 회전각 | **7° 이하**, 모든 프레임 통과 |
| 화면 경계 밖으로 나가는 도형 | **0프레임** |
| 가장 작은 화면 경계 여유 | **약 8.59px** (400×400 캔버스 기준) |

경계 검사는 **모든 정수 프레임**에서 Lottie 키프레임의 베지어 이징, 부모·자식 계층 변환, 회전, 스케일을 계산하고 각 도형의 곡선 외곽을 샘플링했다. 선 두께에 대한 여유 폭도 포함했다. 뿌리인 몸통 회전은 최대 7°이며, **잎 자체의 회전은 감정 표현을 위해 이보다 클 수 있다** (`failure` 잎 최대 39°). 이는 의도한 값이다.

## 패키지 사용

1. `bori_<growth_stage>_<state>.json` 중 해당 단계와 동작을 앱 번들에 추가한다. 모든 JSON은 400×400, 30fps, 투명 배경이다.
2. 동작 연결과 성장 로직은 `BoriReactionEngine.swift`, `BoriGrowthEngine.swift`, `GROWTH_RULES.md`를 참고한다.
3. 각 상태의 GIF 미리보기는 `bori_preview_<growth_stage>_<state>.gif`다.
4. JSON 회전·경계 회귀 검사는 패키지 폴더에서 `node verify_bori.mjs`로 반복 실행할 수 있다. 실행 시 `QA_METRICS.json`을 새로 만든다.

## 남은 iOS 기기 확인

- 이 검사 환경에는 Xcode 및 실제 Lottie iOS 플레이어가 없어 **iOS 네이티브 런타임에서 24개 동작 재생을 검증하지 못했다**.
- 앱에 연결 후 실제 iPhone에서 자세, 표현 애니메이션, 반복·전환, 작은 크기에서의 가독성, `Reduce Motion` 대응을 확인해야 한다.
- GIF 및 수학적 프레임 경계 검사 통과를 **기기 재생 성공**으로 간주하면 안 된다.

참고: [Lottie Specifications — Properties](https://lottie.github.io/lottie-spec/latest/specs/properties/) (애니메이션 스칼라는 길이 1의 벡터 키프레임 사용).

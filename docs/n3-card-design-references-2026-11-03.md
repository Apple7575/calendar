# N3 개념서 카드 재설계 참고 자료

2026-11-03. 이번 변경은 덱 진입 카드 통일과 발견된 오류 1건 보류까지다. 아래 재설계안을 전체 교재에 적용하거나 유료 AI 재생성을 실행한 것은 아니다. 기존 N3/N2 어휘·진도, 개념서 응답·복습 일정은 유지한다.

자료마다 수동 회상·입력·문장 선택에 대한 입장이 다르다. 공통 원칙과 사용자의 ‘타이핑 없이 카드 뒤집기’를 결합한다. 이들을 모두 같은 방법으로 공부하는 ‘공부 잘하는 사람들’로 묶거나 효과를 보장하지 않는다.

## 현재 카드에서 확인한 문제

- 교재 추출 ready 562개 중 basic 368, cloze 125, apply 61, transform 3, audio 5다. `ready`는 기존 자동 검수 상태이며 학습 설계·일본어 정확성의 전수 보증이 아니다.
- 실제 ready 카드 `lab_pdf_p181_b451c6b50cf0`는 앞면 `彼は留学生だ＿＿＿。`, 답 `ようだ`, 보기 `そうだ / ようだ`다. 채우면 `だようだ`가 되어 접속이 맞지 않는다. 단순히 지시문 길이를 줄이는 것으로 고칠 수 없다. 원문과 정답을 임의로 바꾸지 않고 이번에 needs_review로 내렸다. 기존 사용자 수정 카드와 복습 이력은 기존 병합 정책을 따른다.
- `例文 … ～でいい → 이 문장에서의 뜻?` 같은 뜻 회상만으로는 새 상황에서 문법을 선택할 수 있는지 확인하지 못한다. 이해 카드로는 쓸 수 있으나 적용 실력을 대신하는 통계로 해석하면 안 된다.
- 기본 힌트 `문맥과 목표 표현을 확인해 보세요`와 범용 채점 문구는 카드별 판정에 충분하지 않다. 구체적인 혼동 지점과 허용 답안을 적어야 한다.
- 독해·청해의 긴 지문은 단순히 잘라 낼 수 없다. 묶음 문맥과 질문을 유지하고, 해설은 묶음 응답 후 공개한다. 빠른 문법 복습과 구분한다.

## 권장 기본 구조

1. 처음 보는 개념은 짧은 설명·예문을 먼저 볼 수 있게 한다. 설명을 이해하기 전에 빈칸을 찍게 하지 않는다.
2. 문법 기본 카드는 **이해**와 **접속/활용**을 구분한다. 모든 개념에 모든 유형을 기계적으로 만들지 않는다.
3. 앞면에는 회상할 질문 하나와 필요한 문맥만 둔다. 의미 문제에는 정답 의미를 알려주는 힌트를 처음부터 노출하지 않는다. 형태 문제에는 목표 문법을 명시할 수 있다.
4. 뒷면은 **정답 → 짧은 뜻/규칙 → 필요한 경우 자세히** 순서다. 전체 번역을 그대로 재현하지 않아도 목표 의미를 이해했으면 자기 평가할 수 있다.
5. 혼동·반복 오답이 쌓이면 사용자가 선택한 개념에만 비교·새 상황 카드를 추가한다. 기존 카드를 덮어쓰거나 자동으로 카드 수를 늘리지 않는다.
6. 새 예문에서의 적용 성적과 기존 문장 회상 성적을 분리한다. 풀이가 빠르다는 이유로 암기 판정하지 않는다.

### 화면에 적용할 예시 — 교재 인용이 아닌 재설계 예시

**의미 이해 카드**

- 앞: `このケーキ、おいしそうだ。` / `そうだ의 뜻?`
- 뒤: `맛있어 보인다` / `겉으로 본 인상·추측`

**형태 카드 — 별도 평가 목표**

- 앞: `눈앞의 케이크가 맛있어 보임` / `おいしい → そうだ` / `보통체`
- 뒤: `おいしそうだ` / `い를 빼고 + そうだ`

**혼동 시에만 추가할 비교 카드**

- 앞: `雨が降るそうだ。` / `직접 본 징후 / 들은 소식?`
- 뒤: `들은 소식` / `보통형 + そうだ → 전달`

예시는 화면·평가 목표 비교용이며 새 교재 카드로 게시하지 않았다. 이후 대표 개념 몇 개를 이 방식으로 확인한 뒤 범위별 적용을 결정한다. 전체 생성 비용은 기존 누적 $5 제한 안에서 별도로 판단한다.

## 이번 구현과 확인

- ‘내 단어장’의 텍스트 링크를 기존 덱과 같은 Pressable/CardView 행으로 변경했다. 이름, 카드 수, 오른쪽 화살표를 같은 위치에 배치했다. 카드 수는 현재 계정의 개념서 상태에서 읽고 저장 내용은 변경하지 않는다.
- 생성된 배포·검수 백업 폴더를 Metro 탐색에서 제외했다. 미리보기의 EMFILE 오류 복구를 위한 변경이며 실제 앱 자료 폴더는 제외하지 않는다.
- 이번 변경은 로컬이며 TestFlight 39에는 아직 반영하지 않았다. 전체 카드 재설계·언어 전수 검수 완료로 보고하지 않는다.
- 오류 1건 보류 후 기본 카탈로그의 ready는 686 → 685개다. 39번 바이너리에 포함된 원래 수와 구분한다.

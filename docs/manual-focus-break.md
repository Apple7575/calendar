# 수동 휴식과 캐릭터 재생 수정

- 집중 목표 도달은 알림만 발생시킨다. 자동 휴식 전환과 자동 공부 종료를 제거했다.
- 목표를 넘기면 `추가 공부 중`, `+00:01` 형식으로 초과 시간을 표시한다. 실제 집중 초는 계속 증가하고 정지 시간은 제외한다.
- `휴식 시작 · 5분`을 직접 누르면 해당 순간까지 실제 공부를 저장한 뒤 휴식을 시작한다. 휴식은 밝은 크림 배경·초록 진행 원·`☕ 휴식 중` 문구로 구분한다.
- 세로 공부 화면과 가로 타이머 모두 같은 정책을 사용한다. 기존 기록·메모 보상은 수동 종료/휴식으로 생성된 실제 공부 기록을 사용한다.
- 캐릭터의 크기 기반 자동 정지와 화면별 강제 정지 옵션을 제거했다. 완료 등 1회 동작 후에는 A01 대기 동작으로 이어진다. 축하 동작을 반복 재생해 실제 보상을 또 받은 것처럼 연출하지 않는다.
- 접근성 모션 줄이기와 명시적인 검수 정지 프레임, 비활성 화면/앱 백그라운드의 재생 중지는 유지한다.

검증: 47개 테스트 묶음 281개 검사 통과. Chrome에서 실제 SVG 프레임 변화, 축하 → 대기 연결, 모션 줄이기 대표 프레임, 초과 공부 유지, 수동 휴식 및 배경 전환, 실제 초과 시간 저장 확인. 실제 iOS 로티 재생·성능은 기기 확인이 필요하다. 배포는 아직 실행하지 않았다.

# 문법·독해 우선 확장과 합성 청해

**후속 최신 결과:** [문법·독해·청해 209/209쪽 1차 처리](n3-corpus-2026-11-03.md). 교재 추출 학습 가능 562문항·확인 필요 214문항, 기존 포함 학습 가능 686문항, 합성 음성 8개. 아래 ‘전체 전수 추출 전’과 $0.024는 이전 1차 표본 시점 기록이다.

후속 가독성 수정: 긴 음식 추측 문제를 `눈앞의 음식이 맛있어 보임`(눈 아이콘) / `おいしい → そうだ` / `추측 · 보통체`로 표시한다. 기존 표본의 수수·독해·음성 질문도 단문·줄 단위로 정리했다. 이 표현은 네 장 미리보기뿐 아니라 실제 학습·카드 목록·응답 기록·생성 결과 목록에 적용한다. 상황·목표 표현·시제·말투·선택지는 유지하며, 원문/답안/이력과 사용자가 직접 수정한 문장은 덮어쓰지 않는다. 화면 근거는 `.expo/concept-lab-20261102/food-brief-qa.json`, `food-brief-*.png`다.

2026-11-03, `feat/n3-concept-flashcards`. [수동 생성·통계 구현](n3-controlled-generation-2026-11-03.md)의 후속이다. 기존 N3/N2 단어장은 분리·보존하며, 기본 새 학습 범위를 문법·독해·청해로 바꿨다. 예전에 공부한 실험 어휘의 복습 일정은 유지한다. 설정에서 실험 어휘 표본을 다시 포함할 수 있다.

## 이번에 실제 추가한 범위

| 추가분 | 학습 가능 | 보류 |
|---|---:|---:|
| 문법 47개 개념의 뜻 회상·문장 적용 | 94장 | 0 |
| 독해 7개 지문 묶음 | 12문항 / 6묶음 | 장문 2문항 / 1묶음 |
| 합성 청해 3개 음성 묶음 | 5문항 | 0 |
| 합계 | **111문항** | **2문항** |

원래 표본과 합친 카탈로그는 127문항, 학습 가능 124문항, 보류 3문항이다. 이전 교재 원음 미첨부 청해 1문항도 계속 보류한다. 학습 제외한 어휘 표본을 삭제하거나 진도를 초기화하지 않았다.

**전체 PDF 문항을 전수 추출한 결과는 아니다.** 문법은 실제 표에서 47개 개념·형식을 구조화했고, 독해·청해는 교재의 단원 전략을 근거로 새 연습 지문·대본을 작성했다. 새 연습 자료는 `origin: ai`, 개념 근거는 별도 추출 레코드로 기록했다. 교재 원문 문제·대본을 그대로 옮긴 것처럼 표시하지 않는다. 원문/AI 결과는 기존 통계에서 구분한다.

문법 PDF 166–224의 실제 확인 영역, 독해 278·286·296·308·314·330의 학습 전략/구조, 청해 350·356·370의 유형을 근거로 했다. 별도 검토 호출 `gpt-5.4-mini-2026-03-17`이 113문항의 자연스러움·정답·설명·문맥·근거 자체 완결성 등을 확인했고 지적 0건을 반환했다. 이 검토는 원문 충실도나 사람의 전수 검수를 보증하지 않는다. 장문 표본은 언어 검토와 별개로 목표 길이에 미달해 2문항을 보류했다.

## 실제 학습 화면

미리보기 **http://localhost:8082/?conceptDemo=1**. ‘오늘 학습 시작’은 복습·새 학습 한도를 따르며, 홈의 **문법 연습 / 독해 연습 / 청해 연습**에서 영역을 고를 수도 있다. 영역을 바꾸면 중단한 세션을 보존한다. 카드 목록에서 오늘의 우선순위 밖 항목을 직접 골라도 실제 남은 새 학습량·복습 일정·묶음 전체 조건은 지킨다.

읽기와 청해 모두 묶음의 모든 질문을 떠올린 뒤 정답·해설을 함께 공개한다. 청해 앞면에는 질문과 재생 버튼만 보이며 대본은 없다. 마지막 질문 뒤 묶음 정답을 열면 대본도 확인할 수 있다. 휴대폰 답안 입력은 요구하지 않는다.

기존 저장 상태에 새 카드를 추가할 때 기존 카드 ID의 사용자 수정·신고·응답·FSRS는 덮어쓰지 않는다. 새 개념·카드 ID와 음성 경로도 기존 단어장과 구분했다.

## 합성 음성

교재 원음이 없어도 **새 연습 대본을 합성해 청해를 제공한다.** 제작한 자료는 다음 세 가지다.

- 갑작스러운 출장으로 여행 일정을 바꾸는 음성 메시지: 포인트 이해 2문항, 19.632초.
- 토요일 도서관 휴관 안내: 개요·세부 정보 2문항, 18초.
- 무거운 짐을 함께 옮겨 주겠다는 제안: 즉시 응답 1문항, 4.896초.

`tts-1`의 alloy/nova로 MP3를 만들고 `whisper-1`로 다시 전사해 대본과 내용이 일치함을 대조했다. 문장부호, 入り口/入口, 九時/9時 등의 표기 차이는 의미 차이로 취급하지 않았다. **사람이 직접 들은 검수나 iPhone 검증을 수행한 것은 아니다.** UI에 ‘AI 합성 음성’을 표시하며 원래 교재 녹음으로 표시하지 않는다.

MP3는 `assets/concept-lab/audio/`에 저장했다. 해시로 원본 제작 파일과 일치를 확인한다. 재생 때 API를 호출하지 않고, 재실행에서도 이미 생성·전사된 파일을 재사용한다. `scripts/build-concept-listening.mjs`는 이 제작 배치의 TTS 최대 3회·ASR 최대 3회, 입력 1,000자·ASR 파일 90초 제한과 재시도 차단을 둔다. 공개 앱 코드에 유료 키를 넣지 않았다.

**오답 추천 화면에서 새 청해 대본·음성을 만드는 온라인 버튼까지 연결한 것은 아니다.** 현재 그 화면의 온라인 생성은 단일 문자 카드만 지원한다. 기존 ‘직접 체크 → 생성 → 검토 → 추가’ 정책은 유지한다.

## 비용과 서버 상태

사용자가 승인한 **누적 총 $5**에 자료 검수·음성 제작·온라인 오답 변형 비용을 함께 넣었다. 기존 N2의 예산과 분리했다.

| 실제 호출 | 횟수 | 추정 비용 |
|---|---:|---:|
| TTS + 재전사 | 3 + 3 | $0.007705 |
| 113문항 독립 검토 | 1 | $0.016150 |
| 합계 | **7회** | **$0.023855** |

검토 토큰은 입력 12,395 / 출력 1,523. 음성 요금은 [TTS 공식 가격](https://developers.openai.com/api/docs/models/tts-1), 전사는 [Whisper 공식 가격](https://developers.openai.com/api/docs/models/whisper-1), 텍스트는 [모델 공식 가격](https://developers.openai.com/api/docs/models/gpt-5.4-mini)을 기준으로 추정했다. 청구서 대조 완료액은 아니다.

안전하게 음성 배치의 $0.10 예약은 유지했다. 서버가 사용·예약으로 세는 금액은 **$0.116150**, 남은 예약 가능액은 **$4.883850**이다. 온라인 오답 변형 요청은 이 작업 종료 확인 시 0건이다. 서버 예산 행의 `production_micros`·`production_ledger`와 동일한 트랜잭션 잠금으로 제작비와 온라인 비용을 합산하므로 별도 제작이 $5 상한을 우회하지 않는다. 비용 불명 요청은 예약을 유지한다.

`concept_lab_production_budget` 마이그레이션을 실제 적용했다. 로컬 파일은 Supabase CLI로 생성한 뒤, 기존 KST 날짜의 선행 테이블 마이그레이션보다 뒤에서 실행되도록 `20261103000300_concept_lab_production_budget.sql`로 순서를 맞췄다. 일반 클라이언트에는 예산 읽기·수정·예약 RPC 권한이 없다. 서버의 카탈로그와 예산 표시도 갱신했다. 최신 함수 배포 메타데이터는 `.expo/concept-lab-20261102/expansion-backend.json`을 본다.

**앱 바이너리·EAS Update·TestFlight는 배포하지 않았다.** SDK·패키지·네이티브 권한도 변경하지 않았다.

## 검증과 이어갈 지점

- TypeScript, 전체 Jest **55 suites / 335 tests**, 서버 Deno **7 tests**, Screen Time 정적 검사 통과.
- Chrome에서 실제 번들 MP3 재생 성공, 앞면 대본·정답 비공개, 묶음 끝까지 해설 지연, 이전 응답·일정·사용자 수정 보존, 어휘 새 학습 기본 제외, 영역 선택과 카드 병합 확인. 360/390/768px 넘침·페이지 오류 없음.
- 수동 생성 화면의 전체 선택·해제·일일 한도 및 기존 카드 학습 QA도 통과. 실제 유료 온라인 오답 생성이나 iPhone 동작 검증은 별개다.
- 실제 DB 롤백 검증으로 제작 예약이 온라인 요청을 차단하는 것을 확인했다. anon 예산 SELECT와 authenticated 예약 RPC 실행 권한은 false다.
- 어휘 파일을 합치거나 수정하지 않았다. 브랜치와 미커밋 작업을 보존했고 커밋·푸시는 하지 않았다.

PDF 166–374의 **209페이지 렌더링은 준비 완료**다. 이것을 209페이지 추출·검수 완료로 세지 않는다. 실제 확인한 영역은 `progress.json.reviewedRegions`, 새 자료 범위·보류 이유는 `expansion-progress.json`에 기록한다. 원문 전체의 나머지 문법/배열/독해/청해 문제 추출·대조, 장문 2문항 확장, 새 대화의 복수 화자 합성·발음 검수는 후속 작업으로 남아 있다. 전 페이지를 무검수로 학습에 넣지 않았다.

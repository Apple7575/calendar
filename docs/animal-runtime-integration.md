# 동물 Lottie 적용

## 제공 자산

- 원본: animal-runtime-json.zip
- assets/animals/runtime/manifest.json의 C01 북극곰, C02 고슴도치, C03 수달, C04 고양이를 사용한다.
- 각 60개 동작, 공통 JSON 30개. 캐릭터 JSON 합계 8,404,328바이트, 캔버스 512×512.
- PNG/MP4/외부 이미지/표현식은 사용하지 않는다. 원본 JSON의 도형·눈·동작·프레임은 수정하지 않았다.
- manifest의 동작 ID, loop, duration_seconds, poster_frame을 런타임과 검수 화면에서 읽는다.
- scripts/generate-animal-registry.cjs는 Metro가 번들에 포함할 명시적 require 경로를 만든다. JSON 객체는 해당 동작을 처음 선택할 때 로드한다.

## 사용자 화면

설정의 캐릭터 선택은 네 동물을 바꿀 수 있다. 선택은 기기에 저장하며 기존 성장 기록을 덮어쓰지 않는다.

| 장면 | 동작 |
|---|---|
| 홈 인사·복귀 | A02, A10 |
| 아침 시작·저녁 시작 | A04, A05 |
| 이불·양치·복약·운동·명상·독서·필기·정리·내일 준비 | A11~A20, 단계별 매핑 |
| 터치 | A06, A07 |
| 작은 목표·아침·단어·차액·운동·저녁 완료 | A24, A25, A26, A28, A29, A30 |
| 집중 준비·집중·휴식 | A31, A36, A38 |
| 일기 작성·저장·듣기 | A51, A52, A40 |
| 시간 보관·사용 조건 충족 | A54, A55 |
| 실제 성장 단계 변경 | A47, A48 |

나머지 동작도 동작 검수 화면에서 모두 재생할 수 있다. 미정인 성장·꾸미기 조건을 새로 부여하지 않는다.

## 재생 규칙

- 모션 줄이기는 앱 설정과 OS 설정을 함께 존중한다. PNG 대신 같은 JSON을 manifest의 poster_frame에 정지한다.
- loop는 manifest 값 그대로 사용한다. 완료 축하 A24~A30은 1회 재생 후 멈추며 터치로 재시작하지 않는다.
- 전체 화면 축하 아래의 완료 요약은 대표 포즈로 표시한다. 중복 축하 동작을 동시에 실행하지 않는다.
- 화면을 벗어나거나 앱이 비활성화되면 정지하고, 돌아오면 재생 중이었던 장면을 이어간다.
- source가 바뀌면 기존 플레이어를 해제한다. 로드 실패 시 오류 상태를 표시하고 PNG로 대체하지 않는다.
- 공통 배경은 shared JSON의 정지 프레임을 사용한다. 공통 celebration_effects는 1회 재생한다.
- 보상 지급은 기존 저장 로직에서 처리한다. 재생·완료 이벤트에서 보상을 지급하지 않는다.

## 검수

- 웹: http://localhost:8082/?animals=1
- 앱: 설정 > 동물 친구 동작 검수
- 4캐릭터 × 60동작, 대표 프레임, 밝고 어두운 배경, 수동 재생, JS 프레임 간격 측정 도구를 제공한다.
- 검수 화면의 재생 선택은 실제 성장이나 실천 기록을 변경하지 않는다.
- JS 프레임 간격 도구는 현재 실행 환경의 JS 스레드 측정이다. 네이티브 Lottie FPS·GPU·메모리 검사로 표시하지 않는다.

### 이번 환경에서 확인한 항목

- manifest 길이/반복/대표 프레임/파일 크기 일치: 240개 통과
- 공통 자산 30개, 외부 이미지 및 표현식 0개 확인
- Chrome SVG 렌더링: 240개 통과
- 모션 줄이기, 완료 축하 1회 및 터치 재생 방지, 선택 저장 통과
- 실제 화면의 캐릭터 선택 → 루틴 행동 전환 → 전체 완료 및 기존 보상 유지 통과
- TypeScript 및 iOS Hermes 번들 생성 통과

### 미검증: 실제 iOS 기기

현재 Windows 실행 환경에 iPhone 제어·프로파일링 연결이 없으므로 실기 재생과 성능은 확인하지 못했다. 번들 검증이나 Chrome 결과를 iOS 실기 결과로 간주하지 않는다.

실기 확인 절차:

1. 검수 화면에서 네 캐릭터의 A01/A05/A12/A25/A26/A36/A38을 재생한다.
2. 대표 프레임 정지, OS 동작 줄이기와 앱 모션 설정, 백그라운드 복귀를 확인한다.
3. 실제 루틴과 단어 완료에서 한 번만 재생하고 X로 즉시 닫히는지 확인한다.
4. Instruments에서 집중 반복 60초, 완료 10회 진입/종료, 캐릭터 4종 전환을 측정한다. FPS·hitch·CPU·메모리와 반복 후 메모리 회수 여부를 기록한다.
5. 측정 기기·iOS 버전·앱 빌드·설정·측정값을 남긴다. 결과가 없으면 통과로 표시하지 않는다.

이번 요청에서는 EAS Build/Update와 TestFlight 업로드를 실행하지 않았다.

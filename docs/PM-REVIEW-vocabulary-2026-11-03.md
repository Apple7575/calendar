# 단어장·일본어 학습 PM 검토

2026-11-03. `feature/vocabulary`의 `238d691`, `c4abf6f`와 http://localhost:8092/?japaneseDemo=1 첫 화면을 확인했다. 전체 샘플 흐름을 PM이 다시 전수 검증했다고 표시하지 않는다.

## 담당자 후속 지시

1. 문제·상황은 이해 가능한 문장 형태를 유지한다. 이전의 극단적 축약 말투를 복원하지 않는다. 상단의 샘플·시간 안내는 한 곳으로 정리해 실제 문제를 더 먼저 볼 수 있게 한다.
2. `〜つもりだ` 개념의 PDF 근거가 needs_review라면 PDF 200쪽을 확정 근거로 표시하지 않는다. 개념 연결 ID는 유지하고 ‘교재 근거 확인 필요 · 샘플 예문은 별도 작성’으로 구분한다. 근거 판독을 추정해서 채우거나 추가 유료 호출을 하지 않는다.
3. 사용자 원래 요구에 따라 종이 쓰기 경로를 유지하되, 말하기 단계에 사진 링크만 단독으로 두지 않는다. 기본은 말하기이고 ‘종이에 써 볼게요’를 선택하면 같은 상황을 한두 문장으로 작성하라는 안내와 사진 제출 링크를 보여 준다. 기존 BookStudy로 이동할 뿐 샘플 완료가 필기 검수·25분 공부·보상 완료를 뜻하지 않음을 구분한다. 기존 집중 학습의 촬영·사진 제출 컴포넌트는 변경하지 않는다.
4. ‘다섯 표현의 뜻 보기’가 답의 단서가 될 수 있다. 후속으로 이를 연 응답은 도움을 받은 회상으로 구분하고, 혼자 떠올린 결과와 같은 통계로 해석하지 않게 한다. 기존 저장값의 호환성을 유지한다.

위 항목은 PM의 작업 방향이며, 이 문서를 작성하면서 담당자의 UI 파일을 대신 수정하지 않았다. 샘플 채택 여부·정식 보상 연결은 사용자 피드백 후 별도로 결정한다.

## 공용 검수 수정

- `feature/preview-tooling`에서 검수 스크립트 12개를 공통 `PREVIEW_PORT` 설정으로 수정했다. 기본 8082, 단어장 8092, 친구들 8093, 집중 8123.
- PowerShell에서 `$env:PREVIEW_PORT='8092'` 후 원본 스크립트를 실행한다. 복사본은 불필요하다.
- Dot `--pair`도 같은 환경 변수로 허용 웹 출처를 선택한다. 페어링 서버 자체는 `127.0.0.1:8766`이므로 동시 실행은 조율한다.
- 포트·경로와 HTTP 출처 차단 테스트 5개 통과, 변경된 실행 파일 14개 문법 검사 통과. `check-bundled-deck-web.cjs`를 실제 8092 대상으로 실행해 N2 추가·N3 기록 보존·N2 학습 진입 검증 통과.
- 실제 계정 토큰 전송, DPAPI 기록, Supabase 페어링 완료는 이번에 검증하지 않았다. 다른 검수 스크립트 전부의 최신 화면 호환성을 통과했다고 보고하지 않는다.

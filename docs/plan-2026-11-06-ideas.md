# 기획 회의 결정과 실행 계획 (2026-11-06)

기획 회의(발표 6명, 아이디어 18개)에서 팀장이 13개를 골랐다. 겹치는 것을 합쳐 기능 9개로 만든다. 숫자는 팀장이 "추천대로"로 확정했다. 정책 값은 이 문서가 기준이다. 바꿀 때는 팀장 결정을 먼저 받는다.

팀: Paul(PM), Diana(디자인), Felix(집중·보상), Vera(단어장·일본어), Grace(목표), Ethan(전기공사기사, 이번에는 없음)

## 공통 규칙

- 하루는 지금처럼 04시 기준(routineDay)이다. 한 주는 월요일 04:00부터 다음 월요일 04:00까지다.
- 시간과 돈은 묶지 않는다. 시간 보상과 돈 보상은 따로 계산한다.
- 벌점은 지금 벌점 경로를 쓴다. 확인 화면을 거치고, 다음 날 빚 이월 상한 60분을 지킨다.
- 새 저장 필드는 Felix가 routineModel에 추가하고 검증한다. 다른 담당은 Felix가 공개한 함수만 부른다.
- 앱은 iPhone 13 Pro 하나 기준이다. 웹 검사는 실기기 확인을 대신하지 않는다.

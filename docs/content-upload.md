# 콘텐츠 업로드 (2026-11-05 사용자 결정)

학습 탭 `콘텐츠`. 매일 꾸준히 올리기 위한 화면이다. 플랫폼은 `src/lib/content.ts` 한 곳에 모은다. 지금은 인스타 릴스와 유튜브 쇼츠뿐이다.

## 보상
| 플랫폼 | 스크린타임 | 돈 |
|---|---|---|
| 인스타 릴스 | 60분 | 10,000원 |
| 유튜브 쇼츠 | 120분 | 20,000원 |

플랫폼마다 04시 기준 하루 1번이다. 2번째부터 기록만 남는다. 안 올린 날 벌점은 없고, 조회수·좋아요 보상도 없다.

## 인증
링크를 붙여 넣는다. 작업을 노트북에서 하므로 캡처는 받지 않는다. 받는 형식은 `instagram.com/reel/<id>`, `instagram.com/reels/<id>`, `youtube.com/shorts/<id>`, `youtu.be/<id>`이고 `www.`, `m.`, 쿼리를 허용한다. 같은 영상의 다른 표기는 하나로 맞춰 비교한다. `youtu.be`는 쇼츠인지 일반 영상인지 앱에서 구분하지 못한다. 형식만 검사하며 게시물이 실제로 있는지, 본인 것인지는 확인하지 못한다.

같은 플랫폼+id는 영구히 다시 인정하지 않는다. `contentSeenLinks`에 따로 남겨 기록을 정리해도 유지된다.

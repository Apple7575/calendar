# 네 친구 배치와 연속 학습

2026-11-01 사용자 결정 반영.

## 캐릭터 배치

| 캐릭터 | 역할 |
|---|---|
| C01 북극곰 | 아침 루틴과 아침 완료 |
| C02 고슴도치 | 단어 학습과 학습 완료 |
| C03 수달 | 집중 공부와 운동 |
| C04 고양이 | 저녁 루틴, 일기와 휴식 |

홈과 정원의 동반자는 사용자가 고른 친구를 유지한다. 활동 화면은 역할에 맞는 친구를 사용한다. 미리보기에서는 네 친구의 모든 동작을 자유롭게 재생할 수 있다.

역할 배치는 animalCast.ts에서 결정한다. 양치 같은 공용 동작도 아침/저녁 플레이어에서 해당 역할 캐릭터를 명시해, 진행 중 캐릭터가 바뀌지 않게 한다.

## 기존 보리 제거

- 앱에서 보이는 이름, 탭, 설정, 로그인과 위젯 문구를 정리했다. 앱 표시 이름은 루틴 친구들이다.
- 기존 assets/bori와 미사용 보리 생성·검수 도구 9개, 미사용 포스터 레지스트리를 앱 소스에서 제거했다.
- 삭제 전 141개 파일을 .expo/retired-bori-2026-11-01.zip에 보관하고 원본과 ZIP 내용의 SHA-256을 대조했다. 이 복구용 ZIP은 앱에 포함하지 않는다.
- 아이콘·시작 화면·파비콘은 제공된 네 동물의 JSON 대표 프레임으로 교체했다. 안드로이드 단색 아이콘은 발바닥이다.
- OS에서 요구하는 아이콘/시작 화면 PNG만 사용한다. 앱 안의 캐릭터와 모션 줄이기는 계속 JSON을 사용한다.
- 기존 성장·학습·백업 데이터를 읽는 내부 식별자는 호환성을 위해 유지한다. 저장된 기록을 초기화하지 않는다.

## 공부를 계속하는 완료 화면

- 오늘 학습 마치기 버튼을 삭제했다.
- 학습 완료 축하의 주요 버튼은 더 공부하기이며, 학습 탭이나 홈으로 나가지 않고 같은 학습 화면의 추가 분량 선택으로 이어진다.
- 추가 학습 선택을 큰 완료 요약보다 앞에 배치했다.
- 작은 학습 목표의 종료 유도 문구는 보상 보기로 변경했다.
- 공통 단어 완료 화면도 전체 학습 이어하기/더 공부하기를 주요 행동으로 사용한다.
- X, 뒤로 가기, 닫기 같은 직접적인 종료 조작은 유지한다.
- 카드 완료 판정, 채점 취소, 구간별 보상과 지급 기록은 변경하지 않았다.

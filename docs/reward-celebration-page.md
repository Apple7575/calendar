# 공부 보상 전용 페이지

- 계획 입력은 기존 텍스트 방식 유지.
- 계획 저장과 필기 사진 확인이 성공하면 `EarnedReward` 스택 페이지로 이동한다. 기존 화면 위의 Modal이나 패널이 아니다.
- 큰 동물 캐릭터, 이번 적립 시간, 이번 적립 금액, 인정 분량, 현재 사용 가능 시간과 보류 사유를 표시한다.
- 오른쪽 아래 `보상받기`와 왼쪽 위 X 모두 이전 공부 화면으로 돌아간다. 보상은 저장 시점에 처리하며 페이지 진입·종료에는 지급 코드가 없다.
- 계획은 5분, 돈 보상 없음. 사진 금액은 오늘 누적액이 아닌 이번 저장 전후 장부 차이로 계산한다. 돈 보상 꺼짐 및 실제 공부 시간 미충족 대기를 구분한다.
- 완료 동작은 기존 manifest 설정대로 1회, 모션 줄이기에서는 대표 프레임. 소리는 기존 사용자 설정을 따른다.

검증: 타입 검사, 집중 단계/보상 차이 12개 단위 검사, Chrome 모바일 폭에서 계획 저장 → 전용 페이지 → 보상받기 → 2분 시작 및 사진 확인 → 보상 페이지 → 5분 시작, 2시간 재시작. 중복 적립 없음 확인. 실제 iOS 기기의 페이지 전환과 재생 검증은 별도 필요하다. 이번 변경은 아직 배포하지 않았다.

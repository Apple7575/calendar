# 가볍게 시작하는 집중 공부

2026-11-01 사용자 확정: 계획 및 각 공부 단계 완료마다 스크린타임 5분. 사진의 돈 보상은 인정 글자 100자당 500원 유지.

## 단계

| 단계 | 조건 | 추가 스크린타임 |
|---|---|---|
| 계획 | 공부할 주제와 계획 한 줄 저장. 공부 시간·사진 불필요 | 5분 |
| 1 | 실제 집중 2분 + 새 필기 사진 확인 | 5분 |
| 2 | 실제 집중 5분 + 새 필기 사진 확인 | 5분 |
| 3 | 실제 집중 10분 + 새 필기 사진 확인 | 5분 |
| 4 | 실제 집중 15분 + 새 필기 사진 확인 | 5분 |
| 5 이후 | 실제 집중 25분 + 새 필기 사진 확인. 이후 25분 유지 | 매번 5분 |

과목을 바꿔도 단계는 이어진다. 사진 단계에서 인정 글자 수는 돈 보상에 사용하고, 시간 보상은 분량에 관계없이 해당 단계 5분이다. 읽을 수 있는 새 필기가 없는 사진이나 중복 사진은 완료 처리하지 않는다. 계획에는 돈 보상이 없다.

## 2시간 재시작

- 마지막 실제 집중 활동 또는 이번 계획 저장 후 2시간 동안 집중 공부가 없으면 계획 단계로 돌아간다.
- 화면을 열거나 사진만 제출했다고 마지막 공부 시각을 갱신하지 않는다.
- 휴식·일시정지는 집중 시간으로 세지 않는다.
- 계획부터 다시 시작하면 다음 목표는 2분이다.
- 기존 보상과 공부 기록은 유지한다. 새 사이클에서는 예전 집중 시간을 다시 보상에 사용하지 않는다.
- 새벽 4시 잔액 초기화와 아침 첫 사용 조건은 기존 규칙 그대로다. 단계의 재시작 기준은 별도의 2시간 비활동이다.

## 사진과 보상

사진은 조건 시간 전에도 저장할 수 있다. 조건을 채우면 해당 과목의 대기 사진을 한 묶음으로 정산하며, 사진 개수만큼 5분을 중복 지급하지 않는다. 다음 묶음은 다음 단계의 실제 집중 시간이 필요하다.

타이머 숫자를 줄여도 실제 공부 시간이 증가하지 않는다. 중간에 멈춘 실제 집중은 기록하지만, 일시정지 후 오랜 시간이 흘렀다고 그 시간을 공부로 더하지 않는다. 사진 인식 실패·재시도·화면 재진입은 보상을 추가 지급하지 않는다.

배포 전 이미 지급된 손글씨 보상은 유지한다. 대기 사진은 새 계획 시작 시 새 단계에 연결해 이어서 확인할 수 있다.

## 구현과 검증

- focusRamp.ts: 전역 단계, 2시간 재시작, 계획 기록과 5분 지급.
- bookStudy.ts: 2·5·10분 타이머, 실제 집중 기록, 만료한 단계의 계획 진입.
- handwriting.ts: 사진 묶음 정산, 단계 증가, 시간과 글자 수 돈 보상 분리, 중복·백업 검증.
- FocusRampStart: 계획 입력, 다음 단계 시작, 보상 안내.
- 기존 네이티브 손글씨 보상 원장에 계획·집중 시간을 합산한다. 단어·운동·순서 보상과 아침 사용 조건은 변경하지 않았다.
- 전체 테스트 277개 통과.
- 웹 UI: 계획만으로 5분, 2분 타이머, 사진 5분·100자 500원, 다음 5분 타이머, 2시간 후 계획·2분 재시작, 기존 보상 보존 통과. 경과 시간은 검수용 데이터로 조절했으며 실제 개인 기록이나 OCR API는 사용하지 않았다.

## 휴식 조건 (2026-11-05 사용자 결정)
`휴식 5분`은 지금 단계의 목표 시간을 채운 뒤에만 나온다. 기준은 필기 사진과 같은 `focusRunCredit >= required`이고, 상태 변경도 `takeEarnedBreak`에서 막는다. 쉬고 돌아온 뒤에는 그 뒤로 공부한 시간이 지금 단계만큼 다시 쌓여야 `휴식 5분`이 나온다(2026-11-05 사용자 결정, `BookTimer.restedCredit`). 쉬기 전에 채운 시간은 사진 보상, 시계 숫자, 벌점 면제에 그대로 인정된다. 벌점이 붙는 모든 마치기는 `useQuitConfirm`을 지나고 면제면 바로 진행한다.

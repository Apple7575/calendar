# 말하기 (2026-11-05 사용자 결정)

학습 탭 `말하기`. 주제를 고르고, 질문에 말로 답하고, AI의 잘한 점·빠뜨린 점·되묻는 질문을 받는다. 주제는 `src/lib/speakingTopics.ts` 한 파일에 있다.

## 보상
- 단어와 같은 구조다. 공백·문장부호를 뺀 글자를 쌓아 500자 → 1,000자 → 1,500자…(500자씩 증가, 약 2분 30초부터)를 채울 때마다 스크린타임 5분·500원. 상한 없음, 남은 글자는 이월, 04시 초기화.
- 긴 답변의 글자는 전부 인정하고 한 답변으로 여러 구간을 넘으면 그만큼 지급한다. 되묻는 질문 답변은 2배로 인정하고 건너뛸 수 있다.
- 인정하지 않는 경우: AI가 주제와 무관하다고 판정, 패딩성 반복, 오늘 인정된 답변과 거의 같음, AI 답변 없이 마침. 정답 여부는 보지 않는다.
- 같은 질문을 같은 날 다시 해도 인정한다. 지급일은 마친 시점의 하루(04시 기준)다.

## 주제
`임원 면접`(5문항 그대로), `기술 면접`, `일본어 말하기`(ja-JP, 글자 2배 인정), `전기공사기사`(AI 질문이 틀릴 수 있음을 안내), `삶과 생각`(정답 없는 주제, 빠뜨린 점 대신 더 생각해 볼 관점, 상담·진단하지 않음), `기타`(주제를 직접 적음).

## 반복 판정
8글자 묶음으로 잰다. 한 글자가 바뀌면 묶음 8개가 깨진다.
- 한 답변 안 반복: 묶음의 40% 이상이 이미 나온 것이면 반복. 같은 문장을 두 번 말하면 약 50%다.
- 이전 답변과 거의 같음: 묶음의 80% 이상이 오늘 인정된 답변에 있으면 거의 같음. 몇 문장을 고쳐 말하면 이보다 낮다.

## 길이
시간으로 끊지 않는다. 빈 재시작이 연속되면 잠시 멈추고 글을 보존해 이어 말할 수 있다. Apple은 음성 인식 작업을 약 1분에 멈추므로 `continuousListen`이 다시 시작하고 글을 이어 붙인다.
| 항목 | 상한 |
|---|---|
| 저장: 답변 / 되묻는 답변 | 4,000자 / 1,000자 |
| AI 전송: 답변 | 앞 2,000자 + 뒤 1,000자 |
| AI 답변: 잘한 점·빠뜨린 점 / 되묻는 질문 | 각 400자 / 150자 |
| 보관 | 최근 100회 |
| AI 호출 | 하루 100회, 앱에서 센다 |
상한을 넘은 글자도 보상 글자 수에는 인정한다.

## 실기기에서만 확인되는 것
- 약 1분마다 이어 붙는 곳에서 단어가 빠지거나 겹치는지
- Apple의 하루 음성 인식 요청 제한에 걸리는지
- 화면 꺼짐 방지와 다른 앱 다녀왔을 때 이어 말하기

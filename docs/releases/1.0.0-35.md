## 포함한 수정

- 읽는 중인 단어 카드를 고정. 다른 카드의 복습 시각 도달만으로 교체하지 않으며 표시한 카드의 평가를 정상 저장.
- 루틴 타이머의 시작 시 1초 증가 현상 수정. 만료 알림과 초과 시간, 일시 정지·재개 유지.
- 기본 고정 20분 및 단어 하루 60분 상한 제거. 구간마다 필요한 완료 수가 10·15·20·25장으로 5장씩 증가하고 각 구간 5분 적립. 새벽 4시 초기화.
- 완료 화면과 분량 완료 요약에 다음 5분까지 남은 카드 수, 구간 진행률, 제외 카드 수 표시.
- 신고로 제외된 카드가 있어도 실제 남은 분량 완료 시 축하 화면 진입.
- 사용 시간 토글을 누르면 아침 미완료·집중/휴식·취침·권한·잔액 부족·복원 중 등 사유를 안내. 가능한 해결 화면으로 이동. 기기 오류도 팝업으로 표시.
- 집중/휴식으로 잠겨도 남은 잔액은 별도로 표시. 잠금 정책 자체를 우회하지 않음.

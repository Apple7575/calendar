# 복습 예정·채점 취소·돈 지갑

2026-11-01 구현. 빌드 35 배포 이후의 변경이며 아직 배포하지 않음.

## 복습 예정

- 진입: 학습 → 복습 예정. 학습 기록에서도 진입.
- 전체/덱별, 7·30·90일, 날짜별 수량과 선택 날짜의 카드 목록.
- 현재 저장된 FSRS 다음 복습일을 학습일(현지 새벽 4시)로 묶는다. 각 카드는 현재 다음 복습에 한 번만 센다.
- 밀린 카드는 오늘 분량에 포함하고 수를 별도 표시한다. 아직 시작하지 않은 새 카드는 미래 복습 수에 넣지 않는다.
- 신고·보류·비활성 카드는 제외한다. 오늘 숨긴 카드는 당일 복습 대상에서 제외하고, 예정일이 오늘 또는 과거라면 내일부터 표시한다.
- 채점에 따라 날짜와 분량이 갱신된다. 이후의 가상 채점으로 여러 회차를 시뮬레이션한 예상치는 아니다.
- 참고: https://docs.ankiweb.net/manual/stats#future-due

## 채점 취소

자동 카드 교체 방지와 직접 취소를 구분한다. 마지막 취소 이벤트의 ID·복원 회차를 사용해 복원한 카드를 한 번 우선 표시한다. 덱·모드 전환 시에도 해당 취소 이벤트를 올바른 화면에서 소비한다. 복원 후 다시 읽는 중에는 시각만으로 카드를 바꾸지 않는다. 스크린타임의 채점 취소 정산이 진행되는 동안 평가 버튼을 잠근다.

## 돈 보상

실제 송금이나 결제가 없는 개인 사용 예산 장부다. 원화 정수로 기록한다.

### 제안값 및 시작

| 항목 | 제안 금액 |
| --- | ---: |
| 아침 작게 / 전체 | 500 / 1,000원 |
| 저녁 작게 / 전체 | 0 / 0원 (설정 가능) |
| 집 운동 / 헬스장 | 1,000 / 3,000원 |
| 단어 5분 보상 구간 1회 | 500원 |
| 손글씨 5분 실제 보상 | 500원 |

위 값은 제안이며 설정 화면에서 수정 후 **이 금액으로 돈 보상 시작**을 눌러야 지급을 시작한다. 금액 합의 응답이 없는 상태에서 기존 사용자 데이터에 자동으로 켜지 않는다. 시작 전의 실천은 기준선으로 등록하여 소급 지급하지 않는다. 순서 보너스와 이전 타이머 보상은 돈 보상에 넣지 않는다.

### 지급·차감·복원

- 루틴·공부 저장과 같은 `RoutineProvider.update` 작업에 지급 원장과 기준을 함께 저장한다.
- 작은 목표 뒤 전체 완료는 차액만 지급한다.
- 단어 기본/추가 구분 없이 기존 보상 구간 완료 수(`wordRewards.rounds`)로 돈을 지급한다. 응답 수나 완료 화면 재진입으로 지급하지 않는다.
- 채점 취소는 지급된 해당 구간 금액을 정정하고, 재채점으로 다시 완료하면 그 금액을 복원한다.
- 학습일별 금액 기준은 고정한다. 설정 변경은 다음 학습일부터 적용한다.
- 돈 잔액과 지출 기록은 새벽 4시에 초기화하지 않는다. 스크린타임 잔액·아침 사용 조건과 별개다.
- 지출은 양수로 입력하고 원장에는 음수로 기록한다. 지출 취소는 원본을 지우지 않고 연결된 환급 행으로 남긴다. 같은 지출 ID 및 지출 취소는 중복 처리하지 않는다.
- 지출 뒤 학습 보상이 취소되거나 예산보다 더 썼다면 기록을 막거나 지우지 않고 부족 금액을 표시한다. 사용할 수 있는 금액은 0원으로 표시하고 이후 적립으로 채운다.
- 돈 지갑은 기존 루틴 데이터와 함께 저장·백업·복원된다. 복구 시 원장과 기준 형식을 검증한다.

## 검증

전체 253개 테스트 및 TypeScript 검사 통과. 웹에서 날짜별 조회·카드 목록, 채점 취소 시 이전 카드로 돌아가기, 구간 보상 취소와 재지급, 지출·지출 취소, 새로고침 후 원장 유지 및 중복 미지급을 확인했다. 검증용 지갑은 격리한 브라우저 컨텍스트의 합성 데이터만 사용했다.

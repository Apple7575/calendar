# 앱 아이콘

사용자 지시(2026-11-06): "우리 앱 아이콘도 듀오링고 처럼 캐릭터 얼굴 빡 박아두자. 그리고 이것도 앱 아이콘 시간이다 조건에따라서 바뀌게 할수있나?" → "C로 하되 다만 하루 2번 정도만 해서 지루하지 않게 하자. 12시 기준으로하자" → "B로 하자."
시안은 Artifact `앱 아이콘 시안`.

## 그림
- 기본 아이콘(`assets/icon.png`)은 수달 웃는 얼굴이다. 이전의 동물 4마리 2×2 그림을 대신한다.
- 대체 아이콘 12개는 `assets/app-icons/{smile|worried|cheer}-{otter|cat|bear|hedgehog}.png`(1024×1024, 투명 없음)다.
- 연속 실천 위젯과 같은 Lottie 프레임과 표정(걱정 눈썹·땀)을 4배 크기로 다시 그린 뒤 얼굴이 꽉 차게 잘랐다. Lottie 원본은 바꾸지 않았다.

## 바뀌는 규칙 (`src/lib/appIcon.ts`)
- 하루를 04~12시(오전 칸)와 12시~다음 날 04시(오후 칸)로 나눈다.
- 오전: 그날 동물의 웃는 얼굴. 오후: 오늘 실천했으면 신난 얼굴, 안 했으면 걱정 얼굴. 실천했으면 오전에도 신난 얼굴이다.
- 동물은 위젯과 같은 날짜 순서다(수달·고양이·북극곰·고슴도치).
- 한 칸에서 한 번만 바꾼다. 오후에 걱정 얼굴을 본 뒤 실천하면 그때만 한 번 더 바꾼다(B안). 하루 최대 3번.
- 실천 여부는 홈의 `연속 실천`과 같은 `routineStreak`의 todayDone이다.

## 동작 (`src/lib/appIconSync.ts`)
- `expo-alternate-app-icons` 8.0.0(app.json 플러그인)으로 바꾼다. 새 바이너리 빌드가 필요하다.
- iOS는 앱이 앞에 있을 때만 아이콘을 바꿀 수 있고, 바꿀 때마다 시스템 알림창을 띄운다. 12시 정각에 혼자 바뀌지 않고, 12시 뒤 처음 앱을 열 때(또는 연 채로 12시가 지날 때) 바뀐다.
- 마지막으로 바꾼 칸은 AsyncStorage `appIcon.last.v1`에 둔다. 바꾸기에 실패하면 기록하지 않고 다음 기회에 다시 시도한다.
- 웹·Expo Go·테스트에서는 아무것도 하지 않는다.

## 실기기에서 확인할 것
- 설치 직후 홈 화면에 수달 얼굴 아이콘이 보이는지.
- 앱을 열면 알림창과 함께 그날 동물 아이콘으로 바뀌는지, 같은 칸에서 다시 열어도 알림창이 다시 뜨지 않는지.
- 12시 뒤 열면 걱정 얼굴, 실천 저장 뒤 신난 얼굴로 바뀌는지.
- 홈 화면 둥근 모서리에서 얼굴이 잘리지 않는지.

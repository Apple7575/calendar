# 연속 실천 위젯

사용자 지시: "위젯은 듀오링고처럼 이런걸로 하자. 지금 위젯처럼 정보 전달이 아니라 캐릭터랑 불모양에 며칠연속인지 이것만 나오게. … 위젯 디자인 내가 했을때랑 안했을때랑 다르게 가져갈수 있나? 위젯 디자인도 날마다 바뀌고"
시안 승인: 2026-11-06 "위젯 시안 좋아, 빌드 하자". 시안은 Artifact `연속 실천 위젯 시안`.

## 화면
- 2×2(`systemSmall`) 하나. 불, 며칠 연속, 동물만 나온다. 문구와 버튼은 없다. 누르면 앱이 열린다.
- 상태: 연속 0일(연두) · 오늘 안 함 04~18시 평온(남색) · 18~21시 걱정(주황 갈색, 불에 `!`) · 21~04시 다급(빨강, 불에 `!`) · 오늘 함(밝은 배경, 주황 불).
- 다급 시작은 21시다. 취침 잠금 시각과 맞췄다(사용자 승인).
- 그날의 동물은 날짜로 정한다(수달·고양이·북극곰·고슴도치, 4일 주기). 하루 동안은 같은 동물이 표정만 바뀐다. 오늘 함 포즈는 4일마다 두 가지가 번갈아 나온다.
- 배치는 158pt 위젯 기준이다. 동물 폭 128, 위에서 50. 다른 크기에서는 같은 비율로 늘이고 줄인다.

## 숫자와 규칙
- 숫자와 오늘 함은 홈의 `연속 실천`과 같은 `routineStreak(data,dayKey)`다. 기존 위젯 데이터의 `routineStreak`는 다른 계산이라 쓰지 않는다.
- 앱은 App Group의 `streakWidget` 키에 `{current,todayDone,day,nextDay}`를 쓰고 이 위젯만 새로고침한다. 기록이 저장되거나 04시에 하루가 바뀌면 다시 쓴다. 기존 `widgetData` 키는 건드리지 않는다.
- 규칙은 `src/lib/streakWidget.ts`의 `streakWidgetView`와 `targets/widget/StreakWidget.swift`의 `streakView`가 같다. 테스트는 앱을 열지 않은 채 며칠이 지나도 위젯이 홈과 같은 숫자를 보이는지 확인한다.
- 위젯은 앞으로 이틀 치 04·18·21시를 타임라인에 미리 넣는다. 저장값이 없거나 깨졌으면 `-`와 평온한 그림이다.

## 그림
- `targets/widget/images/`의 PNG 29장(동물 24, 불 5), 약 285KB. `expo-target.config.js`의 `images`로 위젯 전용 에셋 카탈로그에 3배 크기 하나로 들어가며 앱 번들에는 없다.
- 동물은 앱의 Lottie에서 대표 프레임을 뽑았다. 걱정과 다급 표정은 입·눈·눈꺼풀 레이어를 숨기고 눈썹, 입, 큰 눈, 땀을 새로 그려 얹었다. Lottie 원본은 바꾸지 않았다.

## 앱 없이 알 수 없는 것
- 오늘 함은 앱이 기록을 저장해야 위젯이 안다.
- 앱을 열어 지난날 기록이 바뀌거나 복구되면, 그때 다시 쓰기 전까지는 이전 값으로 보인다.
- 04·18·21시 그림이 실제로 그려지는 시각은 iOS가 정한다. 늦게 그려져도 그림은 그 항목의 시각 기준이다.

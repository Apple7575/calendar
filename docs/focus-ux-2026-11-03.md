# 집중 학습 흐름 정리

- 브랜치 `feature/focus-ux`, 미리보기 `http://localhost:8123` (`docs/AGENT_PREVIEW_PORTS.md`).
- 집중 단계, 필기 검수, 보상 계산, 앱 잠금 정책과 저장 스키마는 바꾸지 않았다.

## 디자인 기준

별도의 디자인 가이드 문서는 없다. 이 작업은 `CLAUDE_DESIGN_BRIEF.md`, `DESIGN_IMPLEMENTATION.md`, `docs/action-flow-ui-2026-11-02.md`의 기준과 `src/theme`의 토큰을 따랐다.

- 화면마다 먼저 답할 질문 하나와 주요 행동 하나만 둔다.
- 제목, 상태, 주요 버튼, 안내는 한 카드에 넣는다. 카드 밖에 글과 버튼을 흩어 놓지 않는다.
- 보조 항목은 `FocusList` 한 묶음으로 모은다.
- 집중 흐름의 색은 `focusTheme`(큰 타이머 기준) 하나다. `FocusThemeProvider`로 적용하며 화면에 색을 직접 쓰지 않는다. 사용자가 고른 앱 테마는 바꾸지 않는다.

## 화면 흐름

타이머가 켜져 있으면 큰 타이머가 공부 화면이다. `BookStudy`로 들어와도 `FocusTimer`로 바꾼다. 별도의 공부 중 페이지는 없다.

| 단계 | 화면 | 주요 행동 | 보조 |
|---|---|---|---|
| plan | 공부 시작 | 계획 저장 | 메모·기록 |
| start | 공부 시작 | N분 집중 시작 | 메모·기록, 공부 마치기 |
| study | 큰 타이머 | 진행 중에는 없음, 멈춤은 이어서 공부, 단계 충족은 필기 사진 제출 | 휴식, 시간 조정, 다음 시작 위치 |
| break | 큰 타이머 | 쉬는 시간 건너뛰고 공부하기 | 휴식 일시정지, 필기 사진 제출 |
| capture | 필기 제출 | 노트 사진 찍기 | 타이머가 멈췄으면 이어서 공부 |
| submit | 필기 제출 | AI로 읽기 | 다른 노트 찍기 |
| review | 필기 확인 | 저장·보상 받기 | 다시 찍기 |

- 사진 진입점은 타이머의 `필기 사진 제출`이다(`BookStudy {capture:true}`). 시간을 채운 뒤 타이머가 멈춰 있으면 공부 화면이 바로 제출 화면이 된다. 시작 전 화면에는 사진 버튼이 없다.
- 단계를 채우기 전 사진 저장과 보상 대기 정책은 유지했다. 타이머의 버튼은 항상 보인다.
- 타이머의 `돌아가기`는 항상 `Main`으로 간다. 사진에서 뒤로 가면 타이머로, 필기 보상 뒤에는 쌓인 화면을 정리하고 타이머로 돌아간다.
- 우선순위 공부의 `다음 시작 위치 남기기`는 공부 중 페이지 대신 타이머 상단에 있다.
- 메모와 `이 과목 공부 마치기`는 공부 시작과 필기 제출 화면의 목록에 있다.

## 휴식 건너뛰기

`skipBookBreak(data, breakTimerId, id, now)`가 휴식에서 공부로 전환한다.

- 진행 중인 휴식과 일시정지한 휴식 모두 가능하다.
- 쉬는 시간은 공부 시간에 들어가지 않고 보상도 지급하지 않는다. 실제 공부 시간은 휴식 시작 때 저장한 `bookSessions`에 그대로 남고, 과목과 필기 초안도 유지된다.
- 전환 기준은 휴식 타이머 ID다. 연속 입력은 한 번만 전환되고, 휴식 종료 직후의 입력은 공부를 시작하며, 다른 타이머로 바뀐 뒤의 늦은 입력은 무시한다.
- 카운트다운은 이번 단계의 남은 시간부터 이어간다. 25분 단계에서 10분 공부했다면 15:00에서 시작한다. 이미 단계를 채웠으면 단계 시간 전체로 시작한다. 고정 25분을 적용하지 않는다.
- 2시간이 지나 계획이 필요하면 전환하지 않고 계획 입력으로 보낸다.

휴식이 자연 종료된 뒤의 `N분 집중 시작`은 기존처럼 단계 시간 전체로 시작한다. 건너뛰기와 맞출지는 미정이다.

휴식은 이전의 밝은 크림 배경 대신 타이머와 같은 다크 배경을 쓴다(2026-11-03 사용자 요청). `휴식 중` 제목과 문구로 구분한다.

## 필기 제출

- 필기 제출에서 앨범 선택을 제거했다. 일기·식사·스타일 등 다른 기능의 앨범은 그대로다.
- 카메라 권한이 없으면 설정 안내, `설정 열기`, `다시 시도`를 보여 준다.

## 캐릭터

수달 그림은 Lottie 캔버스의 가운데 일부만 차지한다. `FocusStart`는 캔버스를 키우고 위쪽 빈 여백과 발 아래를 잘라 패널 위에 걸쳐 보이게 한다. 잘라내지 않으면 웹에서 투명한 `svg`가 위쪽 탭의 터치를 가로챈다.

## 검증

웹 미리보기는 iOS 검증을 대신하지 않는다. 카메라 권한 거부, 설정 복귀, 가로 잠금, 앱 잠금 연동, 상태 표시줄 색, Lottie 크기와 성능은 실제 iPhone에서 확인해야 한다.

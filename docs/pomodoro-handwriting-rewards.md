# 집중 타이머와 손글씨 보상

2026-11-01 사용자 결정 반영. 현재 work/routine-original 브랜치에서 웹 검토 중이다.

## 사용자 흐름

- 학습 > 집중에서 25분 또는 50분을 선택한다.
- 전용 타이머는 A안의 어두운 화면과 원형 남은 시간 표시를 사용한다.
- 정지/시작, ±1분, ±5분 조절을 제공한다. 타이머가 끝나면 5분 휴식으로 전환한다.
- 과목은 기본으로 숨긴다. 과목 보기로 표시하며 5초 후, 앱이 비활성화될 때 다시 숨긴다.
- 노트 사진은 25분 전에도 촬영·인식·저장할 수 있다.
- 저장된 사진은 보상 대기로 남는다. 같은 과목의 실제 집중 25분이 충족되면 그동안 대기한 사진을 함께 정산한다.
- 한 정산 묶음에 집중 25분을 사용한다. 추가 사진은 다음 집중 25분 조건으로 정산한다. 사용하지 않은 집중 시간은 과목별로 유지한다.
- 재촬영·인식 실패·중복 사진에는 집중 시간을 사용하지 않는다.

## 보상과 데이터

- 인정 문자 100자당 스크린타임 5분, 돈 보상 기본 500원.
- 돈 보상도 실제 집중 25분 조건을 충족한 후 지급한다. 지갑 사용이 켜져 있어야 하며 저장된 사용자 금액 설정과 학습일별 고정 금액은 보존한다.
- 돈은 스크린타임 분량을 환산하지 않고 인정 글자 수로 계산한다. 100자 미만은 이어 모은다.
- 사진의 day는 제출한 실천일이다. 보상이 나중에 지급되면 rewardDay에 적립하며 이전 날의 소진된 잔액을 복원하지 않는다.
- 보상 대기 사진은 순서 보너스의 과목 완료 분량으로 계산하지 않는다.
- rewardStatus, rewardDay, rewardOrder, focusSeconds는 기존 영수증에 선택적으로 추가한다. 예전 영수증과 보상을 다시 쓰거나 소급 차감하지 않는다.
- 정산은 저장 트랜잭션 안에서 처리하며 화면 재진입·새로고침·애니메이션으로 지급하지 않는다.

## 타이머 시간 조절

focusElapsed와 focusResumedAt으로 실제 집중 시간을 추적한다. 사용자가 바꾸는 카운트다운과 별개다.

- 일시정지·휴식은 제외한다.
- 남은 시간을 줄여도 집중한 시간이 증가하지 않는다.
- 남은 시간을 늘려도 이미 집중한 시간이 사라지지 않는다.
- 중간에 끝내면 실제 진행한 시간만 기록한다.
- 기존 타이머는 duration과 remaining에서 실제 경과 시간을 읽어 호환한다.
- 타이머 완료 자체로 루틴을 자동 완료하거나 루틴 보상을 지급하지 않는다.

## 루틴 타임 리밋

루틴 편집에 선택 항목 preparation을 추가했다. 플레이어는 해당 준비 내용, 현재 타임 리밋, 다음 행동을 보여준다. 사용자 루틴과 오늘 이미 시작한 구성은 유지한다. 기존 종료 알림·초과 시간·직접 완료 체크를 보존한다.

## 검증 및 실기 확인

- 단위 테스트: 25분 전 저장/후 정산, 일시정지·휴식 제외, 시간 증감, 과목별 집중 잔액, 중복 방지, 새벽 4시 이월, 돈/시간 동시 정산.
- 웹: A안 원형 타이머, 세로/가로 조작, 과목 숨김/5초 후 숨김, 시간 증감, 조기 사진 저장, 실제 25분 시 자동 지급, 새로고침 중복 없음.
- 웹 체험: http://localhost:8082/?focusDesign=1. 체험 타이머는 실제 기록·보상에 영향을 주지 않는다.
- expo-keep-awake ~15.0.8, expo-screen-orientation ~9.0.9는 Expo SDK 54 호환 버전이다.
- 아이폰 실기에서 가로 전환/복귀, 자동 잠금 방지, 앱 비활성화 후 복귀, 소리·진동, 네이티브 스크린타임 반영을 확인해야 한다.
- 웹 검토 전 EAS Build/Update는 실행하지 않는다.

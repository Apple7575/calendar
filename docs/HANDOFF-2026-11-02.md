## 1. 가장 최근 요청과 현재 멈춘 지점

사용자는 앱이 복잡하고 원하는 흐름이 보이지 않는다고 평가했다. 기능을 계속 붙인 결과 화면마다 현재 행동·설정·보상·기록이 비슷한 비중으로 나오는 것이 핵심 문제다. 단순히 캐릭터 확대·색 변경·카드 재배치만 반복해서는 해결되지 않는다.

사용자와 동의한 방향:

> 미리 할 일을 정한다 → 앱을 열면 지금 할 행동 하나가 보인다 → 작게 시작한다 → 계속 공부한다 → 결과를 제출한다 → 보상을 확인한다 → 다음 행동이나 시간 사용을 선택한다.

각 페이지에서 **핵심 질문과 가장 중요한 행동 하나**를 먼저 정한다. 모든 기능을 홈에 진열하지 않고 필요한 순간에 노출한다. 중요한 공부부터 꾸준히 하게 하고, 시작할 때 고민하는 시간을 없애는 앱이 목적이다. 다른 목표를 모두 순차 잠금으로 막거나 사용자 선택을 없애라는 뜻은 아니다.

사용자는 “AI 티”를 없애고 싶어 Taste Skill과 ECC 설치를 요청했다. 처음에는 선별 설치를 지시했지만 이후 **“아니야 전체 플러그인 켜”**로 변경했다. 전체 플러그인 설치·활성화·실제 로드 검증까지 완료했다.

**최근 설치 요청의 범위는 설치·설정 확인뿐이었다. 설치 중 앱 코드와 화면은 수정하지 않았다.** 지금 요청은 인수인계 MD 작성이다. 이후 앱 개선은 새 세션에서 사용자가 이어서 요청하면 진행한다. 설치만으로 전면 재설계가 이미 끝났다고 말하지 않는다.

- 학습일은 새벽 4시 경계, 과거 진도·기록은 보존. 일반 일정의 민간 날짜까지 전부 이전 실천일로 밀지 않는다.

- **단어 보상 최신:** 완료 카드 10장→5분, 다음 15장→5분, 다음 20장→5분… 매 회 필요량 **5장씩 선형 증가**, 하루 상한 없음, 다음 학습일 10장부터 재시작. 기본 목표 고정 20분이나 하루60분 상한을 되살리지 않는다. `src/lib/studyRewards.ts`, `docs/word-rewards-v2.md` 참고.
- 완료 카드는 비Again 응답 후 다음 예정이 다음 새벽4시 이후로 넘어간 기준. 같은 카드 당일 재응답·재학습으로 중복 보상하지 않는다. 응답 횟수와 완료 수는 구분. 다음 보상까지 남은 카드 수를 안내한다.
- 복습 카드 시간이 도래해도 사용자가 보고 있는 카드가 자동으로 다른 카드로 교체되면 안 된다. 채점 취소는 이전 카드로 복귀해야 한다.
- 손글씨 집중 공부: 계획만으로 5분, 그 뒤 실제 2→5→10→15→25분+필기 확인마다5분. 25분 이상 단계 증가 없음. 마지막 실제 공부/계획 이후2시간 비활동 시 계획부터 재시작. 과목 전환으로 초기화·중복 지급하지 않는다. 계획은 현재 타이핑 방식 유지하기로 최종 번복했다. `docs/gradual-focus-study.md` 참고.
- 사진 돈 보상은 인정 글자100자당500원. 계획 자체에 돈 보상 없음. 시간 보상과 돈 보상 조건을 혼동하지 않는다. 사진은 시간 전에도 제출 가능하나 시간 지급은 조건 충족 시. AI 인식 및 중복 검증 유지.
- 집중 목표 시간이 끝나도 공부는 계속되고 초과 시간 표시. **사용자가 휴식 시작을 눌러야** 휴식. 공부/휴식 색·레이블 명확. 타이머 조정은 실제 공부 시간을 조작하지 않는다. 가로 원형 타이머·화면 꺼짐 방지·과목명 기본 숨김 유지. `docs/manual-focus-break.md` 참고.
- +60분 좋은 순서 보너스는 기존 별도 순서 설정 기준. 첫2분 시작만으로 +60분 지급하지 않는다.
- 돈 지갑은 실제 현금 이체가 아닌 사용자 가용 금액 기록이며 지출 차감 기능이 있다.
- 카드 신고 종류 클릭 시 즉시 저장·닫기, 신고 카드는 학습 제외, 직접 입력·공유/복사·bury/보류 및 재포함 경로 보존.
- 카드 학습 자체의 기본 UI는 사용자가 선호했음. 앞뒤 단어 위치 고정, 큰 터치 영역, 개별 단어/예문 속도, 즐겨찾기/신고/자동 예문 설정 유지. 다른 화면 개선을 이유로 함부로 전면 교체하지 않는다.
- 단어 뒤 예문 자동재생 간격0.5초. 오디오 앞뒤 무음 처리 규칙을 다른 덱 제작에도 사용. 음성을 다시 생성하거나 유료 호출할 때는 현재 범위 확인.

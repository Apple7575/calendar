# 오늘의 일본어 샘플

2026-11-03. 브랜치 `feat/n3-concept-flashcards`. 사용자 제공 설계를 실행 가능한 로컬 샘플로 구현했다. 교재의 개념과 연결하되 예문·지문은 새로 작성했다. 유료 AI 호출·EAS 배포는 하지 않았다.

## 실제 연결 범위

- 샘플 저장은 `routine.japanese-sample.v1.<accountId>`로 분리한다. 질문 ID, 기존 개념 ID, 익숙한/새 상황 구분, 정오·선택·이유·응답 시각을 저장한다. 재진입 시 이어가고 완료 결과도 복원한다. 같은 질문 재응답은 중복 집계하지 않는다.
- 5/8/7/5분은 권장 구성이다. 실제 25분 타이머·정식 FSRS 큐·보상 정산과 연결하지 않았다. 처음 5개도 실제 due 큐가 아닌 고정 샘플이다. 기존 단어장·개념서 일정과 보상은 바꾸지 않는다.
- 완료 화면의 ‘25분 → 5분’은 **보상 미리보기**이며 실제 시간·돈 지급은 없다. 빠르게 넘긴 세션을 실제 25분 공부로 인정하지 않는다.
- 샘플에서 사진 제출로 가는 링크는 없다. 샘플과 사진 검수·보상 정산은 연결되어 있지 않다.
- 말하기는 녹음·음성 인식·AI 채점 없이 실제로 말하고 예시와 비교하는 자기 평가다. 첫 버전은 독해를 선택했으므로 새 듣기 기능은 구현하지 않았다.
- AI 새 문제 자동 생성은 없다. 전체 개념서 카드를 재작성하거나 기존 이력을 초기화하지 않았다.

## 문구 정책

사용자가 짧은 말투 지시를 취소했다. 새 샘플은 상황·질문·해설을 문장으로 작성하고 의미 구별을 묻는다. 기존 개념서의 축약 표시 오버라이드도 비활성화해 원래 작성된 질문과 해설을 사용한다. 저장된 원문·사용자 수정은 유지한다.

## 흐름 점검 수정 (feature/vocabulary)

수정 전 화면에서 재현한 뒤 고쳤다. 샘플 문장·정답·저장 키·저장 형식은 바꾸지 않았다. 고친 한국어 상황 문구는 아래에 적은 2곳뿐이다.

- 응답 전 개념 설명이 해설과 현재 문제의 목표 표현을 보여 주던 문제: 응답 전에는 다섯 표현의 뜻을 함께 보여 주고, 해당 표현의 설명은 응답 후에만 보여 준다. 기본 예문에는 목표 표현이 이미 보이므로 뜻을 펼치면 답을 짐작할 수 있다. 사용자가 직접 펼칠 때만 보이며, 유지 여부는 사용자 확인 대상이다.
- 새 상황 정답이 보기 순서(1→5번)와 같던 문제: 상황 순서를 `japaneseSampleNovelConcepts`로 분리했다. 이어 하기는 질문 ID로 찾으므로 진행 중인 기록도 그대로 쓴다.
- 틀린 표현을 고르고도 ‘이해하고 떠올렸어요’가 보이던 문제: 틀리면 ‘확인했어요 · 다음으로’만 보여 주고 다시 연습으로 저장한다. 고른 표현과 목표 표현을 함께 표시한다.
- 기본 예문 정답과 새 상황 정답 예시에 각각 이름을 붙였다. 결과 화면은 자기 평가와 선택 결과를 ‘맞힘’으로 묶지 않고 구분한다.
- 독해 안내를 실제 조작(답을 생각한 뒤 근거 선택)에 맞췄다. 보조 기술 라벨에 내부 ID가 읽히던 것을 고쳤다.
- 상황 문구: ‘건강을 위해’ 일본어 뉴스를 듣는다는 어긋난 이유와 ‘네가’라는 호칭을 고쳤다.
- 완료 후 다시 해 볼 수 없던 문제: 샘플 기록만 새로 시작하는 링크를 추가했다. 기존 routine/concept-lab 저장소는 건드리지 않는다.

### 사용자 화면 피드백 (2026-11-03)

- 버튼은 해요체를 빼고 짧게 쓴다: `정답 보기`, `맞힘`, `다시 연습`, `다음`. 짧은 말투 취소 지시는 상황·질문·해설에 해당하며 그대로 문장으로 유지한다.
- 막힌 이유는 가로 3칸 버튼(`문법 헷갈림`, `단어 모름`, `단서 놓침`)이다. `다시 연습`을 누르거나 새 상황에서 틀린 표현을 골랐을 때만 나오고, 누르면 저장 후 다음 문제로 넘어간다.
- 평가 방법·진행 시간·기록 영향을 설명하던 안내 문구를 뺐다. 문제를 푸는 데 필요한 지시, 교재 연결 표기는 남긴다. 말하기가 자기 평가이고 음성 채점이 없다는 점은 단계 제목과 결과 화면에, 보상이 미리보기라는 점은 완료 화면에 남긴다.
- 듀오링고를 참고해, 말하기까지 마친 뒤 틀린 카드가 있으면 로티 페이지 ‘틀린 문제 다시 풀어 볼까요?’ → 틀린 카드 반복 → 결과 순서로 진행한다. 맞힐 때까지 반복하고 또 틀린 카드는 뒤로 밀린다. 대상은 기본 예문·새 상황 카드 10장이며, 독해와 말하기는 포함하지 않는다.
- 처음 응답과 다시 풀기는 분리 저장한다(`retries`, 같은 저장 키, 기존 기록 호환). 결과 화면의 첫 응답 점수는 다시 풀어도 바뀌지 않고, 다시 풀어 맞힌 문제 수를 따로 표시한다. 새 문제를 만들지 않고 정식 복습 일정(FSRS)과도 연결하지 않는다.
- 말하기 단계의 사진 제출 링크를 사용자 요청으로 제거했다. `BookStudy` 화면과 그 경로 자체는 바꾸지 않았다.

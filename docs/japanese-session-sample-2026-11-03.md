# 오늘의 일본어 샘플

2026-11-03. 브랜치 `feat/n3-concept-flashcards`. 사용자 제공 설계를 실행 가능한 로컬 샘플로 구현했다. 교재의 개념과 연결하되 예문·지문은 새로 작성했다. 유료 AI 호출·EAS 배포는 하지 않았다.

## 체험

http://localhost:8082/?japaneseDemo=1 또는 학습 탭 → **오늘의 일본어 시작**.

|---|---|---|

| 독해 | 8분 | 안내문 1개·근거 선택 질문 2개, 모두 응답한 뒤 해설 |

| 결과 | — | 13응답, 기본/새 상황/독해/말하기와 표현별 결과를 분리 |

## 실제 연결 범위

- 샘플 저장은 `routine.japanese-sample.v1.<accountId>`로 분리한다. 질문 ID, 기존 개념 ID, 익숙한/새 상황 구분, 정오·선택·이유·응답 시각을 저장한다. 재진입 시 이어가고 완료 결과도 복원한다. 같은 질문 재응답은 중복 집계하지 않는다.
- 5/8/7/5분은 권장 구성이다. 실제 25분 타이머·정식 FSRS 큐·보상 정산과 연결하지 않았다. 처음 5개도 실제 due 큐가 아닌 고정 샘플이다. 기존 단어장·개념서 일정과 보상은 바꾸지 않는다.
- 완료 화면의 ‘25분 → 5분’은 **보상 미리보기**이며 실제 시간·돈 지급은 없다. 빠르게 넘긴 세션을 실제 25분 공부로 인정하지 않는다.
- 종이에 쓴 경우 기존 `BookStudy` 사진 제출 화면으로 이동하는 링크를 제공한다. 샘플과 사진 검수·보상 정산의 통합까지 완료한 것은 아니다.
- 말하기는 녹음·음성 인식·AI 채점 없이 실제로 말하고 예시와 비교하는 자기 평가다. 첫 버전은 독해를 선택했으므로 새 듣기 기능은 구현하지 않았다.
- AI 새 문제 자동 생성은 없다. 전체 개념서 카드를 재작성하거나 기존 이력을 초기화하지 않았다.

## 문구 정책

사용자가 짧은 말투 지시를 취소했다. 새 샘플은 상황·질문·해설을 문장으로 작성하고 의미 구별을 묻는다. 기존 개념서의 축약 표시 오버라이드도 비활성화해 원래 작성된 질문과 해설을 사용한다. 저장된 원문·사용자 수정은 유지한다.

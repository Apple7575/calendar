## 재개 및 산출물

새 자료 작업은 [통합 매뉴얼](../PDF_VOCABULARY_MANUAL.md)을 먼저 읽는다. 이 N2 실행은 입력·출력과 예산이 고정된 전용 스크립트다. 다른 PDF에 그대로 실행하지 않는다.

| 파일 | 역할 |
|---|---|
| `intake.json`, `n3-before.json` | 원본 범위·승인 예산·N3 보존 해시 |
| `source-pages/`, `source-verified*/`, `reconciled-pages/` | 원문 추출·별도 대조·학습 내용 대응 |
| `source-corrections.json`, `manual-language-corrections.json` | 원문/예문 보정 근거 |
| `content-audit.json`, `language-audit.jsonl`, `korean-fields.jsonl` | 수량·중복·텍스트 검수·한국어 설명 |
| `content/n2-vocabulary-content.json` | 텍스트 완성본; 음성 포장 전 |
| `cost-ledger.jsonl` | 실제 요청 예약·사용량 및 보수적 비용 추정. 비밀 키 없음 |
| `audio/manifest.json`, `audio/*.jsonl` | 음성 선택·생성·전사·보정 진행 기록 |
| `audio/file-audit.json` | 최종 선택한 음성의 해시·브라우저 디코딩·무음 검사 |
| `delivery/` | 최종 앱용 덱·전달 자료. 포장 검수 통과 후 생성 |

주요 실행 순서:

1. `prepare-n2-source.py`: 로컬 보존·렌더·OCR. 유료 호출 없음.
2. `prepare-n2-corpus.mjs`: 초안/재대조. 페이지별 성공 파일로 재개하고 동시 요청 잠금 사용.
3. `verify-n2-source-strong.mjs`, 원본 이미지 대조, `reconcile-n2-source.mjs`.
4. `apply-n2-content-corrections.mjs`, `build-n2-deck.mjs`, `audit-n2-language.mjs`, `translate-n2-study-notes.mjs`.
5. `n2-generate-corpus-audio.mjs`, `watch-n2-pronunciation.mjs`, `n2-judge-corpus-transcripts.mjs`, `n2-repair-corpus-audio.mjs`, 필요 시 `n2-recheck-repairs.mjs`.
6. `check-n2-files.cjs`, `n2-finalize-corpus-audio.mjs`, `trim-n2-edges.py`, 재감사, `package-n2-deck.mjs`.

주의: 이미 수동 보정·한국어 설명이 들어간 content를 다시 build/reconcile하면 후속 보정을 재적용해야 한다. 검수 완료 manifest를 generate/finalize로 되돌리지 않는다. 모든 유료 스크립트는 현재 승인 예산과 ledger를 먼저 확인한다. 새 상한 승인을 임의로 기록하지 않는다.

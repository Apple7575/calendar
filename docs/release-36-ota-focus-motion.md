## OTA 자산 검증

최초 업로드는 자산 수 한도 때문에 게시되지 않았다. 이후 실제 EAS 36번 IPA의 `EXUpdates.bundle/app.manifest`를 추출해 해시를 대조하고, 내장된 동일 음성 3,175개만 OTA metadata에서 제외했다. 앱 설정이나 런타임은 변경하지 않았다. Expo SDK의 `assets:verify`가 모든 참조 자산이 설치본 또는 업데이트에 존재함을 확인했다(누락 0개). OTA 자산 39개와 새 실행 번들을 게시했다.

production 채널에서 위 업데이트 ID와 런타임이 내려오는 것을 확인했고, SDK 54의 iOS 모듈처럼 multipart extensions의 자산 요청 헤더를 사용해 실행 번들을 실제 다운로드하여 SHA-256 일치를 검증했다. 인증 헤더는 출력하지 않았다.
